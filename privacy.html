Privacy Policy

Effective Date: October 27, 2026
Application Name: AeroSDR Pro: Flight & Marine Radar
Package Name: com.aerosdr.radio

1. Overview & Zero-Cloud Privacy Commitment

AeroSDR Pro is an off-grid software defined radio (SDR) receiver and avionics/marine decoder developed for pilots, mariners, amateur radio hobbyists, and emergency responders. We operate on a strict, absolute zero-cloud architecture: we do not collect, store, transmit, or share any personal user data, RF spectrum captures, geographic location records, device identifiers, or analytics telemetry.

2. Permissions and Hardware Access

To function as a software-defined radio receiver, AeroSDR Pro requests the following device permissions:

  • USB Host / OTG Permission (android.hardware.usb.host): Required exclusively to communicate with attached USB SDR hardware (such as RTL2832U, HackRF, or Airspy dongles) to stream raw I/Q radio frequency samples into volatile system memory for demodulation. The application never accesses any other USB storage devices or files.
  • Precise Location (ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION): Required solely to center the polar radar PPI display around your current physical ground station coordinates and calculate relative bearing, range (NM), and azimuth to detected aircraft and maritime vessels. Location coordinates remain entirely inside volatile memory and are never uploaded to any remote server or persistent log file.
  • Foreground Service (FOREGROUND_SERVICE_CONNECTED_DEVICE): Required to maintain unbroken USB I/Q sample streaming and real-time Mode-S/AIS message processing while the user switches between viewports or runs the receiver in the field.

3. Zero Third-Party SDKs & Zero Analytics

AeroSDR Pro contains no third-party advertising SDKs, tracking libraries, profiling engines, or cloud telemetry kits (no Google Firebase Analytics, no Facebook SDK, no AppsFlyer, etc.). Demodulated ADS-B flight data and AIS maritime signals are decoded exclusively on your device's local CPU using native mathematical routines.

4. Data Storage & Exports

Any target logs or flight export files generated by the user are stored strictly within the app's local private sandbox storage or exported explicitly via the Android system document picker to a location chosen by the user. AeroSDR Pro has no background network synchronization mechanisms.

5. Children's Privacy

AeroSDR Pro does not target or knowingly collect data from children under the age of 13. The application is completely offline, non-commercial in data handling, and does not require user accounts.

6. Changes to this Privacy Policy

If our privacy practices change in future updates, we will update this document and post notice within the application's documentation repository.

7. Contact Information

For technical inquiries or questions regarding our privacy architecture, please contact our engineering team via our GitHub repository issues portal or developer contact address listed on Google Play.
